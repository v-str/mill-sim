# Contributing

## Code Style

Форматирование по Google Style (см. `.clang-format`).

## Процесс

1. Форкни репозиторий
2. Создай ветку от `dev`: `git checkout -b feature/название`
3. Внеси изменения
4. Собери проект: `cmake -B build && cmake --build build`
5. Открой Pull Request в ветку `dev`
